# Your agents

Put your team's own agent definitions here, one file each: `.reins/agents/<name>.md`, with a `description` (and optionally `tools`) in its frontmatter.

- **A new agent:** create its file here, or ask your agent to use the `agent` skill. `reins sync` also generates `.claude/agents/reins-<name>.md` for Claude Code.
- **Change a reins agent:** copy it from `../core/agents/` here, keep the name, and edit it. Yours wins.

`../core/` belongs to reins: `reins sync` rewrites it on every update, so don't edit it. This README is generated by `reins sync`.
