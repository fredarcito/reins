# Your skills

Put your team's own skills here, one folder each: `.reins/skills/<name>/SKILL.md`, with a `description` in its frontmatter (it is how the agent decides to load it).

- **A new skill:** create its folder here. `reins sync` also generates `.claude/skills/reins-<name>/` for Claude Code.
- **Change a reins skill:** copy its folder from `../core/skills/` here, keep the name, and edit it. Yours wins.

`../core/` belongs to reins: `reins sync` rewrites it on every update, so don't edit it. This README is generated by `reins sync`.
