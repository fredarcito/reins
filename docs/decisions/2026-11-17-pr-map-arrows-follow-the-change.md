# PR map arrows follow the change (2026-11-17)

In a real session neither the person nor the agent could tell, from the picture alone, which way the map's arrows went: they followed the imports (`talentData → shared`), while the boxes tell an impact story (shared changed, talentData is affected). Every edge is now drawn from the code being used to the code using it (`shared → talentData`), structural edges included, so one drawing has one direction; the legend says "the arrow follows the change". Who imports whom stays in words: the diff block ("now uses") and Details ("`a` now uses `b`: `x` imports `y`", no bare arrow).
