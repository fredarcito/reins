# Your policies

Put your team's longer rules here, one Markdown file per topic (for example `testing.md` or `api-design.md`).

- **Make agents read them:** add one line to your part of `AGENTS.md` (outside the `reins:rules` block) saying when to read each file, for example "Writing tests → read `.reins/policies/testing.md`".

reins' own policies live in `../core/policies/`. Don't create files here with the same names: agents and `reins doctor` rely on them.

`../core/` belongs to reins: `reins sync` rewrites it on every update, so don't edit it. This README is generated by `reins sync`.
