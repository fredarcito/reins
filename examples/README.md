# examples

Minimal test projects, one per preset, each with an intentional violation of every rule. The engine's integration tests run against them. Filled in phase 3:

- `vite-react/`: Vite + React in plain JS/JSX, aliases in `jsconfig.json` and `vite.config.js`.
- `next-app/`: Next app router in TypeScript, aliases in `tsconfig.json`.
